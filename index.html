Installation Instructions

iOS & iPadOS (14+)

  1. Download the .mobileconfig file using Safari.
  2. Open Settings and tap Profile Downloaded at the top.
  3. Tap Install in the top-right corner and enter your passcode.
  4. Confirm installation. The profile activates immediately.

macOS (11+)

  1. Double-click the downloaded .mobileconfig file.
  2. Open System Settings → Privacy & Security → Profiles.
  3. Double-click the imported profile and click Install....
  4. Enter your administrator password to confirm.
