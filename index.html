Installation Guide

Detailed steps for installing your DNS profile

📱 iOS Installation

  1. Tap the downloaded .mobileconfig file
  2. Go to Settings → Profile Download
  3. Tap Install and enter your passcode
  4. Confirm installation and restart if prompted
  5. Verify DNS settings in Settings → General → VPN & Device Management

💻 macOS Installation

  1. Double-click the downloaded .mobileconfig file
  2. Open System Settings → Privacy & Security
  3. Find the profile and click Install
  4. Enter your administrator password
  5. Verify in System Settings → Network → DNS
